##########
OpenFinGym
##########

**Agentic Financial Task Creation Pipeline**

OpenFinGym implements a pipeline that automates the extraction of
machine learning tasks from papers, generating tasks in the
`Harbor <https://www.harborframework.com/docs>`_ format for use
in Agentic benchmarking, and SFT and RL LLM training.

This project builds on the work in the paper
`OpenFinGym: A Verifiable Multi-Task Gym Environment for Evaluating Quant Agents <https://arxiv.org/pdf/2606.26350>`_.
